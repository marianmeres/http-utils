## Purpose

Opinionated, lightweight HTTP client wrapper for native `fetch` with:
- Type-safe HTTP errors mapped to specific error classes
- Convenient defaults (auto JSON parsing, Bearer tokens, base URLs)
- Three-tier error message extraction (per-request > per-instance > global)
- Dual API: new options-based API and legacy positional arguments API

## Core Components

### 1. HttpApi Class (src/api.ts)

Main HTTP client class with private fields:
- `#base`: Optional base URL
- `#defaults`: Default fetch params (object or async function)
- `#factoryErrorMessageExtractor`: Error message extractor function

#### Methods

**HTTP Methods (all support dual API):**
- `get(path, options | params, respHeaders?, errorExtractor?, _dumpParams?)`
- `post(path, options | data, params?, respHeaders?, errorExtractor?, _dumpParams?)`
- `put(path, options | data, params?, respHeaders?, errorExtractor?, _dumpParams?)`
- `patch(path, options | data, params?, respHeaders?, errorExtractor?, _dumpParams?)`
- `del(path, options | data, params?, respHeaders?, errorExtractor?, _dumpParams?)`

**Utility Methods:**
- `url(path)`: Build full URL from path
- `base` (getter/setter): Get/set base URL

#### Options Interfaces

```typescript
interface GetOptions {
  params?: FetchParams;
  respHeaders?: ResponseHeaders | null;
  errorExtractor?: ErrorMessageExtractor | null;
}

interface DataOptions {
  data?: any;
  params?: FetchParams;
  respHeaders?: ResponseHeaders | null;
  errorExtractor?: ErrorMessageExtractor | null;
}

interface FetchParams {
  data?: any;
  token?: string | null;        // Auto-adds "Authorization: Bearer {token}"
  headers?: Record<string, string> | null;
  signal?: AbortSignal;
  credentials?: 'omit' | 'same-origin' | 'include' | null;
  raw?: boolean | null;         // Return raw Response object
  assert?: boolean | null;      // Default true, set false to not throw on errors
}
```

## Key Implementation Details

### Request Processing Flow

1. `_fetchRaw()`: Low-level fetch wrapper
   - Normalizes headers to lowercase
   - Auto-sets `Content-Type: application/json` for object data
   - Handles FormData without explicit Content-Type
   - Auto-adds Bearer token from `token` param

2. `_fetch()`: Response processing
   - Returns raw Response if `raw: true`
   - Mutates `respHeaders` object with response headers + `__http_status_code__`, `__http_status_text__`
   - Auto-parses JSON response body
   - Throws HttpError on non-ok response (unless `assert: false`)

### Error Message Extraction Priority

1. Per-request `errorExtractor` parameter
2. Per-instance `factoryErrorMessageExtractor`
3. Global `createHttpApi.defaultErrorMessageExtractor`
4. Built-in fallback: tries `body.error.message`, `body.message`, `body.error`, `response.statusText`

### API Detection Logic

New vs legacy API is detected by checking for specific keys in the options object:
- GET: `'respHeaders' in obj` or `'errorExtractor' in obj` → new API
- POST/PUT/PATCH/DEL: `'data' in obj` or `'params' in obj` or `'respHeaders' in obj` or `'errorExtractor' in obj` → new API

### Deep Merge Behavior

Defaults are deep-merged with per-request params, allowing partial header overrides.

## Usage Examples

### Basic Usage
```typescript
const api = createHttpApi("https://api.example.com", {
  headers: { "Authorization": "Bearer token" }
});

// New API (recommended)
const data = await api.get("/users", { params: { headers: { "X-Custom": "value" } } });
await api.post("/users", { data: { name: "John" }, respHeaders: {} });

// Legacy API
const data = await api.get("/users", { headers: { "X-Custom": "value" } });
await api.post("/users", { name: "John" }, {}, respHeaders);
```

### Error Handling
```typescript
try {
  await api.get("/not-found");
} catch (error) {
  if (error instanceof HTTP_ERROR.NotFound) {
    console.log(error.status);  // 404
    console.log(error.body);    // Response body
    console.log(error.cause);   // { method, path, response: { status, statusText, headers } }
  }
}
```

### Dynamic Configuration
```typescript
const api = createHttpApi("https://api.example.com", async () => {
  const token = await getToken();
  return { headers: { "Authorization": `Bearer ${token}` } };
});
```
